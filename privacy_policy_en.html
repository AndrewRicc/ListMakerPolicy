Privacy Policy — ListMaker

2. Data Collection

ListMaker does not collect any personal data.

The application does not require account creation, does not perform user registration, and does not transmit any data to external servers.

All data entered by the user (list names, categories, and items) is stored exclusively on the user’s device using a local database (Hive). This data is never shared, uploaded, or transmitted.

3. Permissions Requested

The app may request the following system permissions:

Storage Access (read and write)

  • Purpose: To allow the user to import JSON files containing list data, or to export/save their data as JSON files.
  • When: Access occurs only when the user explicitly initiates an import or export operation from the app’s menu.
  • What is read/written: Only the files selected by the user via the system file picker. The app does not independently access any other files on the device.

On Android 13 and later, the app uses modern storage APIs (scoped storage) and does not require additional permissions to access files selected by the user.

4. Third-Party Services

ListMaker does not integrate any third-party data-collecting services, including but not limited to: - Analytics services - Advertising networks - Crash reporting services - Social network SDKs - Cloud or synchronization services

The open-source libraries used by the app (Hive, flutter_slidable, file_picker, etc.) operate entirely on-device and do not collect or transmit any data.

5. Data Security

User data is stored locally on the device and protected by Android’s built-in security measures. ListMaker does not operate any servers, remote databases, or network connections.

6. Children’s Privacy

ListMaker does not collect personal data from any user, including children. The app is suitable for all age groups.

7. User Rights (GDPR)

In accordance with the General Data Protection Regulation (GDPR — EU Regulation 2016/679), users have the right to:

  • Access their data: all data is visible directly in the app or exportable as JSON.
  • Rectify their data: any item can be edited directly within the app.
  • Erase their data: all data can be deleted from within the app or by uninstalling the application.
  • Data portability: the JSON export feature allows users to obtain a readable copy of all their data.

Since no data is transmitted to external systems, no additional procedures are required to exercise these rights.

8. Changes to This Policy

Any changes to this Privacy Policy will be published on this page with an updated “Last updated” date. We encourage you to review this page periodically.
