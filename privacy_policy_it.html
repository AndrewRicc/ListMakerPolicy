2. Dati raccolti

ListMaker non raccoglie alcun dato personale.

L’applicazione non richiede la creazione di un account, non effettua registrazioni utente e non trasmette dati a server esterni di alcun tipo.

Tutti i dati inseriti dall’utente (nomi di liste, categorie ed elementi) sono memorizzati esclusivamente in locale sul dispositivo dell’utente, attraverso un database locale (Hive). Questi dati non vengono mai condivisi, caricati o trasmessi.

3. Permessi richiesti

L’app può richiedere i seguenti permessi di sistema:

Accesso allo storage (lettura e scrittura)

  • Scopo: Consentire all’utente di importare file JSON con dati di liste o di esportare/salvare i propri dati in file JSON.
  • Quando: L’accesso avviene solo quando l’utente avvia esplicitamente un’operazione di importazione o esportazione dal menu dell’app.
  • Cosa viene letto/scritto: Esclusivamente i file scelti dall’utente tramite il selettore di file di sistema. L’app non accede autonomamente a nessun altro file sul dispositivo.

Su Android 13 e versioni successive, l’app utilizza le API di storage moderno (scoped storage) senza richiedere permessi aggiuntivi per accedere ai file scelti dall’utente.

4. Servizi di terze parti

ListMaker non integra alcun servizio di terze parti che raccoglie dati, inclusi ma non limitati a: - Servizi di analytics - Reti pubblicitarie - Servizi di crash reporting - SDK di social network - Servizi cloud o di sincronizzazione

Le librerie open-source utilizzate dall’app (Hive, flutter_slidable, file_picker, ecc.) operano interamente in locale e non raccolgono né trasmettono dati.

5. Sicurezza dei dati

I dati dell’utente sono conservati in locale sul dispositivo e protetti dalle misure di sicurezza del sistema operativo Android. ListMaker non gestisce server, database remoti o connessioni di rete.

6. Dati dei minori

ListMaker non raccoglie dati personali di nessun utente, inclusi i minori. L’app è adatta a tutte le fasce d’età.

7. Diritti dell’utente (GDPR)

In conformità al Regolamento Generale sulla Protezione dei Dati (GDPR — Regolamento UE 2016/679), gli utenti hanno il diritto di:

  • Accedere ai propri dati: tutti i dati sono visibili direttamente nell’app o esportabili in formato JSON.
  • Rettificare i propri dati: qualsiasi elemento è modificabile direttamente nell’app.
  • Cancellare i propri dati: tutti i dati possono essere eliminati direttamente dall’app o disinstallando l’applicazione.
  • Portabilità dei dati: la funzione di esportazione JSON consente di ottenere una copia leggibile di tutti i dati.

Poiché nessun dato viene trasmesso a sistemi esterni, non è necessaria alcuna procedura aggiuntiva per esercitare questi diritti.
